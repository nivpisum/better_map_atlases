# Changelog

## 1.0.1 — 2026-10-04

- Require only Forge and Map Atlases to be present; remove added version bounds
  and the independent Moonlight dependency requirement.
- Clearly separate the verified environment from other, untested combinations.
- Dedicate original code and documentation under CC0-1.0, without attribution;
  retain third-party asset terms.


## 1.0.0 — 2026-10-04

First public release. Verified with Minecraft 1.20.1 / Forge 47.4.23 / Java 17.

- Separate explored surface and cave pages, with cave history shared across heights.
- Accurate texture and biome colours, height-aware cave navigation, and preserved exploration with the book.
- Configurable full-screen atlas and minimap, dimension navigation, banner pins and shears editing.
- Faster nearby updates and bounded synchronization, cached page lookups and background computation for large cave histories.
- Simplified Chinese and English controls, project description and logo.

The verified combination used Map Atlases 1.20-6.0.20 and Moonlight
1.20-2.16.35-forge. Existing map records are retained.
